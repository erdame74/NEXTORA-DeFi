# NEXTORA DeFi

Interfaz web estática de NEXTORA DeFi.

## Publicación en Cloudflare Pages
- Rama: `main`
- Build command: ninguno
- Build output directory: ninguno
- Root directory: ninguno

El sitio entra por `index.html` y no necesita Node.js ni un proceso de compilación.

## Incluye
- Dashboard sin elementos de ciclos/puntos de Impulso Capital.
- Planes de 1, 7, 15 y 30 días.
- Tasas mostradas: 0,65%, 0,75%, 0,85% y 1,00% diario.
- Rango de referencia: $20–$1.000 USD.
- Calculadora de rendimiento estimado.
- Referidos de hasta 5 niveles.
- Interfaz para USDT BEP20/TRC20 y retiros con comisión indicada del 3%.
- Logo NEXTORA DeFi integrado en tamaño visible.

Los módulos de conexión de billetera y procesamiento real de depósitos/retiros requieren una integración backend/gateway antes de manejar fondos reales.
